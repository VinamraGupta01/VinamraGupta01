## `01` &nbsp; ABOUT ME

I'm a **BCA student and backend-focused full-stack developer** focused on building practical, scalable and deployable web applications.

My primary focus is **Java backend development** — designing REST APIs, implementing business logic, securing applications with Spring Security and JWT, and working with relational databases through JPA and Hibernate.

On the frontend, I use **React** to build responsive interfaces that integrate cleanly with backend services. I also work with **Docker, Git and deployment workflows** to take applications beyond local development.

**Current focus:** Backend Engineering · DSA · System Design · Production-ready Applications
